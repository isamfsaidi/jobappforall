# Libyan Market Place

This is a simple web application for a Libyan marketplace, built with Flask and SQLite.

## How to Run

1. **Install dependencies:**
   ```bash
   pip install Flask
   ```

2. **Run the application:**
   ```bash
   python app/app.py
   ```

3. **Open your browser and go to:**
   ```
   http://127.0.0.1:5000/
   ```
